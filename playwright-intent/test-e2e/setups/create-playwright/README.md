# create-playwright

What `npm init playwright@latest` (create-playwright 1.17.139) writes for a TypeScript suite with only Chromium, Firefox and WebKit selected and no GitHub Actions workflow. The template's `{{testDir}}` is filled in as `tests`, and its browser markers are removed.

Files end in `.txt`, so the formatter leaves Playwright's own style alone. `gitignore.txt` is the `.gitignore`.
